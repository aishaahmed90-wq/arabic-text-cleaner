Remove Tashkeel from Arabic Text

Remove Arabic tashkeel, harakat, and diacritics instantly. This tool removes the diacritics while keeping the original Arabic letters unchanged.

What does this tool remove?

The tool removes Arabic diacritical marks such as fatha, damma, kasra, sukun, shadda, and tanween.

It does not change Arabic letters or words. Only the tashkeel is removed.

Example

Before: السَّلَامُ عَلَيْكُمْ

After: السلام عليكم
